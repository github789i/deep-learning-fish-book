# 📖 Introduction

**Deep Learning Fish Book Notes** is a personal learning repository that records code implementations, experiments, and study notes while learning deep learning based on the classic book:

> 📘 **Deep Learning from Scratch (鱼书 / 深度学习入门)**

This repository follows the chapter structure of the book and gradually implements core deep learning algorithms from scratch.

The project focuses on:

- 🧮 Mathematical foundations of deep learning
- 🧠 Neural network implementation
- 🔥 Activation functions
- 📉 Loss functions
- ⚙️ Optimization algorithms
- 🔄 Backpropagation
- 🖼️ Computer vision basics
- 🚀 Deep learning model training

The goal is:

> **Understand the internal mechanisms of deep learning models by implementing algorithms step by step.**

Instead of directly using high-level frameworks, this project emphasizes:

- Understanding algorithm principles
- Writing core components manually
- Building deep learning intuition

| Component | Version |
|---|---|

---

## 1. Clone Repository

```bash
git clone https://github.com/yourname/deep-learning-fish-book.git

cd deep-learning-fish-book
```

---

## 2. Create Virtual Environment

Using conda:

```bash
conda create -n deep-learning python=3.10

conda activate deep-learning
```

